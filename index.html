Comprovante Timemark

A imagem será convertida em Base64 no navegador para o envio; não será salva localmente.
Informe um endereço HTTPS completo.

Não inclua informações pessoais no comprovante além do necessário. O link do comprovante será registrado na aba “Registros do aplicativo” da planilha de cópia. Imagens enviadas são armazenadas no Drive e podem ser abertas por qualquer pessoa com o link; para links informados, confira as permissões de acesso.

O envio só será confirmado quando a API responder com JSON status: "ok".
